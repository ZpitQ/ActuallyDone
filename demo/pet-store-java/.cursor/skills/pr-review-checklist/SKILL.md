## 分档产出

评审结论按三档给，每条附「文件:行号 + 会发生什么后果」：

- **阻断**：违反不变量、有数据/资金风险、破坏兼容性。必须改。
- **建议**：可维护性问题，本次或下次改都行。
- **可选**：风格偏好。最多三条，多了会淹没前两档。
